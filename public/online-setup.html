Play from anywhere.
Add voice when you're ready.

The game already works locally. These steps set up your own public game address and optional voice. The Windows download does not create accounts or activate paid services.

1. Get an online game address

  1. Create your account at Render using GitHub.
  2. Choose New → Web Service, connect Cognitive-Science-Memory-Game, and select codex/mind-mosaic for this update. Use main after the update is merged.
  3. Choose Node and the Free plan. Set the build command to corepack enable && pnpm install --frozen-lockfile && pnpm build and the start command to node dist/server.cjs.
  4. Add these environment values, and set the health check to /api/health:
    NameValue
    NODE_VERSION24.19.0
    TRUST_PROXY1
    DATA_DIR.data
  5. Create the service. Once it is live, open its https://…onrender.com address and make a room.
The free preview sleeps when idle and can lose rooms on restart. For a sustained contest session, review an always-on plan with a persistent disk. Choosing a paid plan is up to you. See Render's limits.

2. Add room voice

  1. Create a project at LiveKit Cloud. Review current plan limits and billing before choosing.
  2. Find the project's WebSocket URL, API key, and API secret.
  3. In your Render service's Environment settings, add LIVEKIT_URL, LIVEKIT_API_KEY, and LIVEKIT_API_SECRET. The URL starts wss://. Save and redeploy.
  4. Create a game room and enable Room voice under Classroom & accessibility. Each player chooses Join voice, then uses Hold to talk.

Use the public HTTPS address on phones. Text and clue cards remain available. Keep API secrets in the service's environment settings; never paste them into chat or a course pack.

3. Build cards from your course

Open Content studio → My materials. Paste your own notes or choose a document, then check the local text preview. Make glossary drafts works without an account. You can try the sample glossary.

AI drafting is optional and uses a creator's OpenAI API key. Review the cost and text-sharing consent, generate, then review every card's source passage and choices. Players never need a key. ChatGPT subscriptions and API usage are billed separately.

Detailed steps and troubleshooting ↗

Local voice connections and muting have been tested with eight synthetic clients. Human microphones, phones, WAN performance, and a paid AI request still need your account setup and playtest. Check the release page for any separately hosted preview.
