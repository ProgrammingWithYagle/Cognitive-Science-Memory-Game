# Mind Mosaic 0.2.0

Leaving a match no longer strands the remaining players. Competitive matches continue; Team Mosaic redistributes the unfinished round's clues. Temporary team disconnects recover automatically when the missing player returns or the reserved seat expires. Completed scores remain saved.

- Question boards stay on the current question after selection. Use arrows or numbered tabs to skip, revisit and revise before locking.
- Five presets: **Baby, Easy, Normal, Hard, Insane**. Memory load increases from three to nine objects while study/answer windows decrease. Old room settings remain compatible.
- Arrow attention now asks **which side the arrow is on**, varies both sides and ignores pointing direction. Stroop color words are enabled by default; Focus Clash appears in every mode and has an immediate unscored practice button.
- Expanded studio: **121 courses across nine universities**, including all 58 CWRU COGS entries; 103 topic starters plus General Play. Presets share original introductory cards and are not complete syllabi.
- Local TXT/Markdown/CSV/TSV/PDF/DOCX import, source previews, glossary drafting, required review, manual editing and JSON sharing.
- Optional LiveKit voice: listen-first joining, hold-to-talk, host mute, quiet private phases and text fallback. Optional creator-only OpenAI drafting: transient keys, cost consent, cancellation and source checks.
- Guided online setup and Render free-preview configuration. The download does not create accounts or activate paid services; any hosted preview is a separate service.

Validation: **188 automated tests**, production/type checks, a **30-minute wall-clock test** (43 matches, 45 leaves, 204 reconnects, five checkpoint restores, zero errors), an 80-client burst test, eight native WebRTC clients exchanging synthetic audio, and browser checks for navigation, both attention tasks, PDF/DOCX import and review. Details are in docs/VALIDATION_0.2.0.md.

Extract the Windows ZIP, then double-click the executable. Windows x64; no separate runtime or installation. The executable is unsigned. Human phone/microphone testing, public WAN performance and real paid AI output require creator setup and playtests; this is a playtest prerelease.
