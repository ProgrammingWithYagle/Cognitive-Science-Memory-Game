# Mind Mosaic 0.1.0 — playable local core

The first playable build of Mind Mosaic is ready for local playtesting with 2–8 people joining by room code.

Includes Recall Rally, Focus Frenzy, Team Mosaic, randomized scenes and sequences, studied course facts, attention tasks, private cooperative fragments, captain/vote/clue controls, reveals, scoring, and the final memory mosaic. Also includes seven starter collections, manual content editing/import/export, facilitator/shared display roles, reconnects, saved room checkpoints, and rematches.

**Windows download:** extract the portable ZIP and double-click its executable. It includes the required runtime. Use the lobby’s network invitation link/QR code for phones on the same network. The host must keep the app open. The executable is unsigned.

**Verified:** 36 automated cases, a completed two-tab browser match, and the built portable executable’s background startup test. A burst test passed with 10 rooms and 80 connected simulated clients, disk checkpoints, complete matches, reconnects, and rematches on one Windows machine with accelerated game time.

This is a prerelease for testing the core. Public hosting, optional voice, optional creator-only AI drafting, the full course library, real eight-person device testing, and final contest polish remain for later milestones. Course starters use public topic descriptions and cited introductory material; they are not instructor-approved syllabi or assessments of ability.
