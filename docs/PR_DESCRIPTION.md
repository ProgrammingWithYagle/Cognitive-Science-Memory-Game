Players can now create a room, join by code from their own devices, and complete matches in Recall Rally, Focus Frenzy, or Team Mosaic. The local core includes server-owned scoring and timers, private cooperative fragments, course starter packs and manual authoring, reveals and a final memory mosaic, reconnect/checkpoint handling, and a self-contained Windows portable app.

Validation: 36 automated cases pass across all modes and player counts; type checking and production builds pass; a four-round two-tab browser match completed; an accelerated burst test passed with 10 rooms and 80 connected clients; the built portable executable passed its startup/frontend self-test with occupied-port fallback.

This v0.1.0 milestone is for local playtesting. The full course library, public hosting, optional voice and AI drafting, real eight-person device testing, and final contest polish remain. The Windows executable is unsigned. Scope and evidence are documented in docs/CORE_BUILD.md.
