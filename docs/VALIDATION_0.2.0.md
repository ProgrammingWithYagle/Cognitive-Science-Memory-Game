# v0.2.0 validation and remaining checks

Local validation on Windows x64, October 4–5, 2026. Evidence distinguishes synthetic checks from human playtests.

- **188 automated cases pass**. Full matches cover all three modes, all five difficulties and every player count 2–8; score totals and ties, private fragments, captain/host restrictions, duplicate/late answers, explicit Leave and reconnects across phases, seat expiry, checkpoint restores, spectator churn and eight real Socket.IO clients. Attention tests cover 100 seeds each for arrow location/direction conflict and Stroop word/ink conflict.
- Type checking and production browser/server/runtime builds pass. The optional LiveKit browser chunk is about 518 KB before compression and loaded only for voice; the PDF worker is loaded only for PDF reading. The build reports a chunk-size advisory for LiveKit.
- All 104 packs validate, supply enough distinct facts for ten rounds, and generate valid rounds across all modes/difficulties. Course metadata covers 121 entries/nine universities/58 CWRU COGS entries; the limitations of shared introductory material are explicit.
- [Thirty-minute endurance test](validation/soak-0.2.0.json): 24 WebSocket bots across three eight-player rooms using real timers and disk checkpoints. **43 matches, 45 leaves, 204 reconnects, five server restarts and zero errors**. Local acknowledgement p95 **23.51 ms**, maximum **139.1 ms**. This is not a WAN or human latency measurement. At completion the process used about 88 MB RSS.
- [Burst smoke](validation/load-smoke.json): ten simultaneous rooms/eighty clients, full four-round matches, reconnects, rematches and checkpoints; accelerated clocks. Use the report's version/date to identify its latest run.
- [Public preview](validation/online-0.2.0.json): eight synthetic clients completed a real-timer four-round match on the free Render service. Explicit Leave, invalidated-session rejection, returning as a spectator, and interrupted-connection resume passed. The hosted browser also connected, created a room and opened color-word practice. The public invitation uses its HTTPS address.
- [Voice media verification](validation/voice-0.2.0.json): eight native LiveKit/WebRTC clients received synthesized audio, host muting blocked publishing, private game phases blocked publishing, and Leave removed the SFU participant. The official v1.13.7 Windows server ZIP was checked against its GitHub SHA-256. No user's microphone was opened. The vendor server is not packaged with the game.
- AI requests were tested with a **simulated provider**: fixed official endpoint, nonstored Structured Outputs request, cost/output bounds, creator ownership, same-origin/HTTPS gate, required consent, exact source quotes, invalid alternatives, dropped unsupported cards, cancellation/expiry, service limits and sanitized errors. **No paid real-model request** or AI factual-quality review has been performed.
- Browser checks: manual answer selection stayed on question 1; tabs/arrows skipped and returned while preserving choices. Stroop displayed **BLUE in red ink**, and arrow position changed between sides. [Stroop screenshot](validation/screenshots/stroop-0.2.0.jpg), [arrow screenshot](validation/screenshots/arrow-0.2.0.jpg), [course library](validation/screenshots/library-0.2.0.jpg).

No console warnings/errors were captured for these imports. File-picker automation initially timed out on the label control; clicking the actual file input succeeded.
